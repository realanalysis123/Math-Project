# Math-Project
A collection of mathematics and statistics write-ups typeset in LaTeX. This repository only contains the typeset results (`.tex` source files and compiled PDFs), such as proofs, derivations, and worked solutions.

## Contents

| Topic | Description | Files |
|-------|-------------|-------|
| Linear Algebra Proofs | Collection of proofs on matrices and linear algebra (e.g., matrix products, transposes, induction proofs) | `main.tex`, `All_Linear_Algebra_Proof_Kristian.pdf` |

More topics in mathematics and statistics will be added over time.

## Repository Structure

```
Math-Project/
├── main.tex                                 # LaTeX source
├── All_Linear_Algebra_Proof_Kristian.pdf    # Compiled PDF
└── README.md
```

## How to Read

Open the `.pdf` file directly on GitHub to view the compiled document. The `.tex` files are provided as the source.

## How to Compile

The documents were written and compiled on [Overleaf](https://www.overleaf.com). To compile locally, install a LaTeX distribution such as [TeX Live](https://www.tug.org/texlive/) or [MiKTeX](https://miktex.org/), then run:

```bash
pdflatex main.tex
```

Run the command twice if the document contains cross-references or a table of contents.
